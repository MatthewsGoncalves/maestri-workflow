### Andar

Clone isolado `Backend`. Branch própria. Não toque outras stacks.

### Antes de codar

Leia **somente** notas listadas na linha **CTX** do seu `maestri ask` (ver overlay worker-context).
**Proibido** ler `handoff` se `handoff:no`. Sem CTX → reporte **blocked**.

### Ao concluir

1. `maestri ask "{{ORCHESTRATOR_CODENAME}}" "Status: needs-review | ..."`
2. **`/clear`** (obrigatório)
3. Aguarde Orchestrator **`maestri dismiss`** — não fique ocioso no canvas

### Skills

Só leia skills **citadas** pelo Orchestrator + default da stack (ver role).

Paths: `skills/installed/<id>/SKILL.md`
